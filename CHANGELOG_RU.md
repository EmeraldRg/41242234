# MiniAssist 1.9.3

- Aim Assist переписан: простая наводка на ближайшую к прицелу видимую цель в радиусе (до 100 блоков), скорость 1-10, точка прицела (голова/тело/ноги), «через стены», цели по типам.
- TriggerBot: режимы «только криты» и «по пробелу» теперь работают — перед критическим ударом бот снимает спринт (ваниль не даёт крит в спринте).
- FreeCam: скрывается рука, чтобы камера выглядела отдельной от игрока.
- Новый модуль FreeLook (Player): осмотр мышью без поворота игрока, по умолчанию удержание LAlt.
- Zoom перенесён в категорию Player.

# MiniAssist 1.9.2 (правки)

- FreeCam перенесён в категорию Player, InventoryMove — в Movement.
- TriggerBot: настройка «Тип удара» (1: без критов, 2: только криты, 3: по пробелу — зажат пробел = криты, иначе без критов). Клик по строке — следующий режим, ПКМ — предыдущий.
- Aim Assist: дистанция в блоках (до 20) считается до ближайшей точки хитбокса, FOV до 360, скорость наводки сильно увеличена по умолчанию.
- Target HUD: слайдер «Target HUD: время (сек)» в модуле HUD — цель остаётся на экране после потери.
- FreeCam переписан в стиле Replay Mod: игрок стоит на месте, камера летит покадрово и без коллизий, отключено отсечение чанков (видно под землёй), клики не доходят до игрока. Клавиша включения — в ClickGUI (по умолчанию F8).
