# MiniAssist 1.9.1 — порт HUD в стиле Expensive 3.1

Клиентский Fabric-мод для Minecraft **1.21.4**, требуется Java 21.

## HUD

Перенесена структура элементов из присланного Expensive 3.1: раздельная ватермарка, список активных модулей слева, XYZ/BPS, перетаскиваемые KeyBinds, Potions и StaffList, Target HUD с головой игрока и броня. Используются собственный бренд MiniAssist, встроенный шрифт Minecraft и самостоятельная отрисовка; приватные логотипы, шрифты и ресурсы Expensive не включены.

Нажми **T**, чтобы открыть чат и перетаскивать панели. **Right Shift** открывает ClickGUI. Позиции и настройки сохраняются в `config/miniassist.properties`.

`StaffList` работает эвристически по префиксам scoreboard и наличию игрока в списке сервера. Сервер может скрывать или подделывать эти данные — это не надёжный детектор модераторов.

## Дополнительные функции

- AutoSprint — обычный ванильный спринт по вводу.
- InventoryMove — движение с открытым контейнером/инвентарём.
- AutoTool — выбор предмета с лучшим ванильным множителем скорости добычи блока под прицелом.
- Zoom — плавное изменение FOV с возвратом исходного значения.
- Keystrokes остаётся дополнительной панелью и по умолчанию выключена.

Aim Assist, TriggerBot и FreeCam из MiniAssist сохранены. Модули не обходят античит сервера и не гарантируют одинаковое поведение на всех серверах.

## Сборка

Workflow: `.github/workflows/build.yml`. Используются Java 21 и Gradle 8.12. Загрузи содержимое проекта в корень GitHub-репозитория. После успешного запуска Actions скачай Artifact **MiniAssist-1.9.1**, внутри `zenith-client-1.9.1.jar`.

Полную локальную Gradle-сборку в среде подготовки выполнить не удалось; компиляцию должен подтвердить GitHub Actions.


## HUD по мотивам Expensive 3.1

Реализованы восемь отдельных элементов из компоновки референса: Watermark, Array List, Coordinates/BPS, Potions, KeyBinds, Target HUD, Armor и Staff List. Добавлен дополнительный переключаемый Keystrokes. Панели перетаскиваются через чат `T`, позиции сохраняются. Используется собственная графика MiniAssist и стандартный шрифт Minecraft; закрытые текстуры и шрифты исходного клиента не включены. Staff List определяет возможных модераторов по scoreboard-префиксам и является эвристикой, а не гарантированным детектором.

## Дополнительные модули

- `AutoSprint` — обычный ванильный спринт.
- `InventoryMove` — движение с открытым контейнером.
- `AutoTool` — выбор инструмента с лучшей скоростью добычи.
- `Zoom` — плавное изменение стандартного FOV.
- Также доступны `Aim Assist`, `TriggerBot` и `FreeCam`.
